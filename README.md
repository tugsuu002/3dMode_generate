# Зургаас 3D загвар (фотограмметр)

Объектоо тойрч авсан зургуудаас COLMAP-аар 3D загвар үүсгэдэг локал вэб апп.
Зураг чирж оруулах UI, явцын заалт, шууд урсах лог, дотроо 3D харагчтай.

    python3 server.py        # → http://localhost:8123

## Юу шаардлагатай вэ

NVIDIA GPU (CUDA) болон Docker. COLMAP-ийн нягт (dense) сэргээлт CUDA шаарддаг
бөгөөд Ubuntu-гийн `colmap` багц CUDA-гүй бүтээгддэг тул Docker образ ашиглана.

**1. Docker-т GPU дамжуулах** (нэг удаа):

    sudo bash setup-gpu.sh

Энэ нь `nvidia-container-toolkit`-ийг суулгаж, docker-т бүртгээд, төгсгөлд нь
`docker run --gpus all` ажиллаж байгааг шалгана.

**2. COLMAP образ:**

    docker pull colmap/colmap:latest

**3. ALIKED-ыг GPU дээр ажиллуулах (заавал биш, гэхдээ зөвлөмжтэй):**

    docker build -f Dockerfile.cudnn -t colmap-cudnn:latest .

`colmap/colmap` образ дээр ONNX Runtime-ийн CUDA хэсэг байдаг ч түүний шаарддаг
`libcudnn.so.9` дутуу. Тэр үед COLMAP нь CPU руу шилжихийн оронд `abort()` хийж,
docker-ийг өлгөдөг. `Dockerfile.cudnn` тэр дутууг нөхнө.

> **cuDNN 9 нь compute capability 7.0 (Volta) ба түүнээс дээш GPU шаарддаг.**
> GTX 10xx (Pascal, sm_61) зэрэг хуучин картан дээр сан нь ачаалагдана ч
> конволюц ажиллахдаа `no kernel image is available for execution on the device`
> гээд унана. `recon.sh` нь `nvidia-smi`-аас GPU-гийн үеийг уншиж, 7.0-аас
> доош бол ALIKED-ыг автоматаар CPU дээр ажиллуулна. Өөрийн GPU-гээ шалгах:
>
>     nvidia-smi --query-gpu=name,compute_cap --format=csv

`recon.sh` нь образ болон GPU-гийн үеийг хоёуланг нь шалгаж, ALIKED-ыг GPU
эсвэл CPU дээр ажиллуулахаа өөрөө шийднэ.

## Онцлог ялгагчийн горим

UI-аас сонгоно, эсвэл `FEATURES` орчны хувьсагчаар:

| Горим | Хэзээ хэрэглэх |
|---|---|
| `sift` | Стандарт, хурдан. Текстуртэй объектод хангалттай. |
| `sift-hard` | Илүү олон цэг, доогуур босго. Удаан (CPU SIFT). |
| `aliked` | Сурсан ялгагч + LightGlue тааруулагч. **Бараан, гөлгөр, текстур багатай объектод.** |

### Бодит хэмжилт

32 зурагтай бараан барималын жишээн дээр (720p, шахагдсан зураг):

| | SIFT | ALIKED + LightGlue |
|---|---|---|
| Бүртгэгдсэн зураг | 17 / 32 | **32 / 32** |
| Дундаж онцлог цэг | 874 | 1,595 |
| Нягт цэг | 24,883 | **62,927** |
| Торны орой | 12 (бүтэлгүй) | **157,304** |

Гурван бие даасан ажил ижил үр дүн харуулсан.

## Зураг авах зөвлөмж

Үр дүнг хамгийн их тодорхойлох хэсэг:

- Объектыг **тойрч** 20–60 зураг. Зэргэлдээ хоёр зураг **60–80% давхцсан** байх.
- Хоёр өндрөөс тойрвол дээд/доод тал нь бүрэн гарна.
- **Зургаа мессенжерээр бүү дамжуул.** Telegram/WhatsApp зэрэг нь EXIF устгаж,
  720p болгож жижигрүүлээд дахин шахдаг — мэдээллийн ихэнх нь тэнд алдагдана.
  USB кабель эсвэл «эх хэмжээгээр» тохиргоо ашигла.
- Объект болон гэрэл **хөдлөхгүй**. HDR/portrait горимыг унтраа.
- Дэвсгэр нь **текстуртэй** байвал сайн (сонин, хээтэй даавуу). Цэвэр цагаан муу.
- Гялгар, тунгалаг, нэг өнгийн гөлгөр гадаргуу муу сэргээгддэг.

## Файлууд

| Файл | Үүрэг |
|---|---|
| `server.py` | Локал вэб сервер. Зөвхөн Python стандарт сан. |
| `recon.sh` | COLMAP-ийн 8 үе шаттай процесс (Docker дотор). |
| `web/index.html` | Зураг оруулах UI + Three.js PLY харагч. |
| `setup-gpu.sh` | `nvidia-container-toolkit` суулгах скрипт (sudo). |
| `Dockerfile.cudnn` | cuDNN 9 нэмсэн COLMAP образ (ALIKED-ыг GPU дээр). |
| `jobs/<id>/` | Ажил тус бүрийн зураг, лог, гарц. Git-д ордоггүй. |

## Гарц

    jobs/<id>/dense/fused.ply   өнгөт нягт цэгэн үүл
    jobs/<id>/dense/mesh.ply    Poisson гадаргуу (гурвалжин тор)

Браузераас харж, татаж авна. Blender-т шууд импортлогдоно.
`http://localhost:8123/?job=<id>` гэж нээвэл хуучин ажлыг дахин үзнэ.

## Тохируулга (орчны хувьсагчаар)

4 GB VRAM-тай GPU-д тааруулсан утгууд `recon.sh` дотор. VRAM хүрэлцэхгүй бол:

    DENSE_MAX=800 CACHE_GB=2 ./recon.sh jobs/<id>

Илүү сайн чанар:

    DENSE_MAX=1600 FEAT_MAX=2400 FEATURES=aliked ./recon.sh jobs/<id>

Бусад: `POISSON_DEPTH` (10), `POISSON_TRIM` (6), `STEP_TIMEOUT` (7200 сек),
`COLMAP_IMAGE` (образыг гараар сонгох).

## Анхаарах

- **GPU дараалал:** олон ажил зэрэг эхлүүлсэн ч `flock`-оор ээлжлэн гүйнэ.
  Нэг GPU дээр зэрэг ажиллуулбал бие биенээ удаашруулж, VRAM дүүрвэл унадаг.
- Дискний зай: нэг ажил 1–5 GB эзэлнэ. Хуучин ажлуудаа `jobs/`-оос устгаж бай.
- Нягт гүний зураглал хамгийн удаан — 30 зурагт 10–40 минут.
- SfM амжилтгүй болвол ихэвчлэн давхцал багатай эсвэл бүрэлзсэн зураг шалтгаан.
